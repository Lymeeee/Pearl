## 介绍

### 实现的功能

**一、主页教务系统部分**  
1.课表：查看你的课表，支持正常学期和小学期。三击空白格子可以添加自定义课程。上方爱心按键为亲情课表功能，你可以导入/导出课表，室友，爱人，甚至老师的日程一手掌握。上方小眼睛按键按下后隐藏上课地点，方便截图分享给校内生人，不留安全隐患。可以获取小学期课表，但请在课表获取后在"更多"页面设定小学期开始日期。在有课程时首页大卡片会显示详情。  
2.教务账户：登录本研一体的地方。受学校系统限制，登录过一段时间会被自动注销掉。  
3.考试：查看考试科目，考场，时间等信息。点击你想看的科目显示详情。  
4.成绩：查看成绩，右上角有按钮可快速计算加权，也有按钮可查看总排名与比例。点击你想看的科目可以查看成绩占比，单科排名。

**二、主页生活服务部分**  
1.自习选座：图书馆选座和研修室预约。像12306一样优雅便捷的体验，选好时间，按下确定，好了。首页大卡片会在今日有预约时显示详情。  
2.无课教室：查看无课教室，数据来自学校官方，和逸夫楼一楼大屏完全一致。（注：请勿在连接vpn时查看，否则会加载不出来）  
3.网络服务：登录校园网账号，查看剩余流量和管理登录设备。点击"限额"可设定限额；点击"套餐"可呼出快速计算；点击"修改密码"可修改密码。（注：请在连接校园网时使用，流量和校外网络无法登陆。若想在连接流量或校外网络时使用，请使用WebVPN自行转换https://zifuwu.ustb.edu.cn ）  
4.流量查询：查看校园网流量使用与账单数据。  
5.电费查询：输入电表号即可查询电费，若每天都查询的话可以根据你的数据绘图。（注：电表号贴在宿舍电表箱上，为8位数字）  
6.WebVPN：在输入框内键入你想访问的校内网站，按下回车后会通过图书馆的WebVPN创建可在校外访问的URL，复制到浏览器即可一键回校。（注：当然也可以把WebVPN转为校内链接，不过我相信没有人会这么做）

**三、其他页面**  
1.配色方案：可切换亮色模式/暗色模式/跟随系统。  
2.调色板：第1个颜色为跟随安卓系统的自动莫奈取色，其余颜色针对不支持莫奈的设备设计，比如初次打开app后默认强调色是蓝紫色的系统。国产安卓！说的就是你！  
3.考试模式：一键删除缓存课表，首页"考试"板块提到最前，方便查询考场信息，同时桌面小组件同步显示考试信息。  
4.假期模式：一键删除缓存课表并禁用小组件，在来年开学手动获取课表时将被自动关闭。  
5.小学期开始日期：为支持课表运作而设置的功能，顾名思义。  
6.触感反馈：在支持的设备上可以启用触感反馈。  
7.电池优化：在安卓系统上，桌面小组件正常刷新必须关闭电池优化，本功能提供了快捷入口。  
8.网络测试：测试网络连通性与出口延迟，点击"启动"即可查看当前的出站网络情况。

**四、附加功能**  
1.桌面小组件：本功能支持安卓，ios与macos，小组件在有课时显示本节课的名称，时间和地点以及授课老师，在无课时显示"今日课毕"，在周末时显示周末问候，在开启假期模式后显示假期问候 ，在开启考试模式时显示最近的一门考试。

## 使用方法

1. 请[**前往此页面**](https://github.com/Lymeeee/Pearl/releases)下载适合你的操作系统的程序文件。
2. 安卓版请下载apk并且无视风险强行安装。
3. Windows版请下载exe并双击运行安装程序。
4. Linux版使用AppImage即可。
5. iOS版需要自签，巨魔或越狱才能安装，由于财力有限故不会上架app store。
6. macOS版右键打开dmg后将应用拖放至Applications文件夹内即可在程序坞见到它。若弹窗提示"无法打开Pearl，因为无法确认开发者身份"，那么请移步至设置 隐私与安全性，划到下面，点击允许任何来源的应用程序，如果有确认是否运行Pearl的地方，请点击仍要运行。
